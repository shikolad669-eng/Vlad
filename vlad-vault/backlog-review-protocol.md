# Backlog review — the session protocol

Trigger: Vlad says «сессия: бэклог» (or any wording to that effect). The ritual
runs on demand. Inherited from the skandar base 2026-07-10.

## Route

1. **Empty the inbox.** For each file in `inbox/`: route by kind —
   external material → [[vlad-vault/field-radar|field-radar]] · idea/vision → `ideas/` (meta if
   cross-domain, else the domain's ideas) · task → executor domain +
   **one line in [[vlad-vault/backlog|backlog]]** · personal development → `for-vlad/`.
   Unsure → ask Vlad in plain text. Inbox file is then deleted or moved.
2. **Walk [[vlad-vault/backlog|backlog]] top to bottom.** For each line: still alive? status
   moved? duplicate (merge, keep one)? ripe (idea → decision / dispatch down)?
   dead (drop WITH a one-line why)? Check the meta↔domain seam: meta holds
   cross-domain canon, domain holds операционка — no third copies.
3. **Walk the fixed shelf list:**
   - domain hot-states: `~/vlad/music/music-vault/status.md` ·
     `~/vlad/study/study-vault/status.md` ·
     `~/vlad/content-factory/content-factory-vault/status.md`
   - projections: `~/vlad/danny-content/posts/README.md` (журнал — источник
     правды) + `HOME.md ## Posts` sync · `~/vlad/public/HOME.md`
   - personal loop (structure only, no content retelling): `~/vlad/vlad-life/`
   - meta shelves: `ideas/README` index · `field-radar` review-marks ·
     `for-vlad/` queue · `plans/` полка
   Cheap freshness check: domain `updated:` newer than the registry line's
   context → the line is suspect.
4. **Report to Vlad:** what ripened · what's stuck · **what he has not
   finished** (the agent's standing right and duty — see [[vlad-vault/preferences|preferences]]) ·
   what was dropped and why. Move closed items to `## Done`, prune old entries.

## Boundaries

- The session curates the registry and shelves — it does NOT execute domain
  work (dispatch it instead, per orchestrator role).
- Every route-out leaves a registry line; every drop leaves a why.
- Frequency: on demand.
