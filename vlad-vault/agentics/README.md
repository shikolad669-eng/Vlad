# agentics/ — метод агентской разработки (зона)

Cross-project method for agentic dev + the accumulator of runs. Lives at the
meta level because it spans **all** work domains.

## Where the canon lives (referenced, not copied)

The method canon (pipeline, roles, constitution, context, errors,
lessons-schema, bootstrap) is **not copied here** — it lives in Skandar's
namespace (`~/skandar/skandar-vault/agentics/` on his machine) and is read from
there during joint sessions. This follows the method's own portability rule:
one method, many projects — referenced, not copied; improving it once
propagates everywhere.

Horizontal axis model (streams / flows / meta-layer) — [[../workflow-streams]];
terms — [[../glossary]].

## What accumulates here

- `runs/` — run-retros of THIS namespace's agentic runs (a folder is created
  with the first run). Run-data stays in the project (`trust: primary`); only
  the retro is lifted here.
- `lessons/` — graduated lessons (trigger → rule → why).
