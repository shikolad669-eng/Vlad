# vlad-vault

meta-vault верхнего level'а: vault *о самом неймспейсе* — связи **вниз** ко всем
доменам. Семантическая карта — начинать отсюда. Конвенции — [[principles]].
Растёт по мере надобности, один файл = один объект.
