# meta-philosophy/ — методология мышления

**Что это:** зона про то, как меняются сами способы думать — не «что решили»,
а «как пришли и почему не приходили раньше». Методология мышления владельца и
оркестратора над задачами всех уровней.

Зона рождена пустой (2026-07-10, зеркало структуры базы): наполняется из
собственных мета-сессий Влада — механизмы, практики, прецеденты слома рамки.
У Скандара аналогичная зона выросла из его мета-сессий; его канон — референс
жанра, не копируется.

## Состав зоны (по мере рождения)

- `mechanism` — канон механизма мышления (когда сформулируется).
- `practice-*` — практики.
- `precedents/` — датированные случаи слома (или несмены) рамки.
