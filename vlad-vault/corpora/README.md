# corpora/ — зарезервировано (движка нет)

Зона для заметок *о корпусах* — источниках, подключённых к retrieval-движку
(RAG). Сам движок в этом неймспейсе **не подключён** (решение при рождении
2026-07-10: «раги и пайплайны не к чему» — отложено, не отменено).

Когда движок появится: один файл = один корпус (что это, пути `source-paths`,
`trust`, зачем подключён). Сами корпуса в vault не копируются — живут по пути.
