# plans/ — полка, не календарь

Стратегические сборки и планы-на-чтение. **Не** зона календарных обязательств —
это правило унаследовано из базы Скандара (его прецедент 2026-07-07: WIP-лимиты
и «активные» планы без ежедневного драйва не пережили контакта с реальностью).

Обязательства ведутся иначе:

- **Захват** → [[../inbox/README|inbox/]] (кидай что угодно, zero ceremony).
- **Реестр** → [[../backlog]] — все живые пункты одной строкой.
- **Ритуал** → [[../backlog-review-protocol]] («сессия: бэклог»).

Здесь лежат: планы-на-чтение перед диспатчем (оркестратор пишет — Влад читает —
исполнитель получает), стратегические сборки, ретро выполненных планов
(`status: done | reference`).
