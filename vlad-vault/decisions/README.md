## Conventions

- Filename: `YYYY-MM-DD-<slug>.md` (identity = the decision date).
- Frontmatter: `type: decision`, `status: accepted | active | superseded`,
  `date`, `tags`, `related`.
- A superseded decision stays (provenance) with a pointer to what replaced it.
