# people/ — реестр идентичностей

Одна карточка на человека, который живёт в **≥2 доменах** или важен поперёк
неймспейса. Карточка отвечает «кто это» (имя, алиасы, ID, где ноды) — **не**
«что он значит»: прочтения остаются в доменах.

## Схема карточки

```yaml
type: person
relation: personal | public | historical
aliases: [все разъехавшиеся написания]
ids: { vk: …, tg: … }   # только уже всплывшие
sensitivity: private     # по умолчанию
```

Тело: 1–2 строки кто это → «Ноды по доменам» (указатели) → «Заметки реестра»
(не-склеивать, открытые вопросы идентичности).

## Правила

- Живой кросс-доменный человек → богатая карточка тут; доменный материал —
  канон в домене, тут — идентичность и указатели.
- Разъехавшиеся написания сводятся `aliases`.
- Имена файлов — lowercase english (`skandar.md`), контент русский.
