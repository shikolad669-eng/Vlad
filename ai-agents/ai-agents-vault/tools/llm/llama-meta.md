# Llama (Meta)

Назад к [[ai-agents/ai-agents-vault/tools/llm/README|LLM Wiki]]

## Кратко
Открытые (open-weight) модели от Meta. Главный плюс — можно **разворачивать у себя**, без зависимости от чужого API и с контролем данных.

## Параметры и фичи
- Актуальные версии/размеры: ⚠️ уточнить
- Контекст: ⚠️ уточнить
- Цена: своя инфраструктура (GPU) либо хостинг у провайдеров (Together, Groq, Fireworks и т.п.)
- Возможности: локальный запуск (Ollama, vLLM), дообучение (fine-tune).

## Когда выбирать
- Нужна приватность данных / self-hosting.
- Хочется контроль и отсутствие оплаты за токены чужому API.
- Дообучение под узкую задачу.
