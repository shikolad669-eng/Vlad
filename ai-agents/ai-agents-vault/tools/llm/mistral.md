# Mistral

Назад к [[ai-agents/ai-agents-vault/tools/llm/README|LLM Wiki]]

## Кратко
Европейский провайдер (Франция). Есть и открытые, и закрытые модели. Часто хвалят за хорошее соотношение цена/качество и компактные модели.

## Параметры и фичи
- Актуальные модели: ⚠️ уточнить
- Контекст: ⚠️ уточнить
- Цена: ⚠️ уточнить (обычно конкурентная)
- Возможности: API + open-weight варианты для self-hosting.

## Когда выбирать
- Нужен баланс цена/качество.
- Европейский провайдер / требования к юрисдикции данных.
- Лёгкие модели для дешёвых задач.
