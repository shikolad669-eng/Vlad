# Глоссарий LLM

Назад к [[ai-agents/ai-agents-vault/tools/llm/README|LLM Wiki]]

Здесь — только про **модели**. Понятия про самих агентов (агентный цикл, tool use,
MCP, гардрейлы, контекст-инжиниринг) — [[ai-agents/ai-agents-vault/glossary|glossary домена]].

- **Токен** — кусочек текста (примерно ¾ слова), в них измеряют объём и цену.
- **Контекст (context window)** — сколько токенов модель «держит в голове» за один запрос.
- **Промпт** — входной текст/инструкция для модели.
- **System prompt** — базовая инструкция, задающая роль и правила поведения.
- **Температура** — «креативность»: ниже = стабильнее и предсказуемее, выше = разнообразнее.
- **Tool use / function calling** — модель вызывает внешние функции (запись, поиск, CRM).
- **RAG** (Retrieval-Augmented Generation) — подмешивание документов клиента к запросу, чтобы отвечала по актуальным данным. Основа [[ai-agents/ai-agents-vault/systems/subscription|базы знаний]].
- **Fine-tuning** — дообучение модели на своих данных.
- **Embedding / вектор** — числовое представление текста для поиска по смыслу.
- **Инференс** — процесс генерации ответа моделью.
- **Latency (латентность)** — задержка до ответа.
- **Open-weight / open-source** — модель с открытыми весами, можно запускать у себя.
- **Prompt caching** — кэширование части промпта ради экономии и скорости.
- **Hallucination (галлюцинация)** — уверенный, но неверный ответ; лечится RAG и проверками.
