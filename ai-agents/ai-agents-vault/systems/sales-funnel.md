# Воронка продаж

Назад к [[ai-agents/ai-agents-vault/HOME|карта домена]]

## Схема

```
Холодный аутрич / контент  →  Заявка
        →  Демо на ИХ данных  →  Оффер (пакет)
        →  Договор + предоплата  →  Внедрение
        →  Подписка на обслуживание
```

## Каналы привлечения

- **Холодный аутрич** — директ/почта владельцам бизнесов из выбранной [[ai-agents/ai-agents-vault/market/niches|ниши]].
- **Контент** — короткие видео/посты «как ИИ-агент закрыл X для салона Y».
- **Партнёры** — маркетинговые агентства, интеграторы CRM (реферальный %).
- **Кейсы** — каждый успешный клиент = материал для продажи следующих.

## Убойный приём: демо на данных клиента

Собери агента на **их** FAQ/прайсе за пару часов и покажи вживую. Клиент видит своего бота, отвечающего его клиентам → возражения «а сработает ли» отпадают.

## Оффер

Продавай не «бота за N рублей», а: *«Агент, который отвечает вашим клиентам за 5 секунд 24/7 и разгружает администратора. Внедрение + сопровождение»*.
