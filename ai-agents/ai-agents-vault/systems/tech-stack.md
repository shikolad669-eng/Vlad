# Технологический стек

Назад к [[ai-agents/ai-agents-vault/HOME|карта домена]]

> [!info] Принцип
> На старте — минимум своего кода, максимум готовых платформ. Кастом добавляешь, когда упрёшься в ограничения.

## Слои

| Слой | Варианты |
|---|---|
| **Модель (LLM)** | Claude (Anthropic API), плюс запасной провайдер |
| **Оркестрация / сборка** | no-code платформы для агентов, либо свой бэкенд |
| **База знаний (RAG)** | Векторное хранилище + документы клиента |
| **Каналы** | Виджет на сайт, WhatsApp/Telegram API, интеграция с CRM |
| **Телефония** | Голосовые платформы (для агента-ресепшн) |
| **Мониторинг** | Логи диалогов, алерты по «не знал ответа» |

## Два пути

- **Быстрый (no-code):** собираешь на готовых конструкторах. Плюс — скорость, минус — потолок и зависимость от платформы.
- **Кастомный (код):** свой бэкенд на API модели. Плюс — контроль и маржа, минус — время и поддержка.

**Рекомендация:** старт на no-code для первых клиентов и кейсов → переход на кастом, когда поток стабильный и нужна маржа/контроль.

> [!tip] Про модель
> Для качества ответов бери актуальные модели Claude через Anthropic API. Детали по моделям/ценам — уточняй перед стройкой, не по памяти.
