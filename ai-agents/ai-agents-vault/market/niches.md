# Клиенты и ниши

Назад к [[ai-agents/ai-agents-vault/HOME|карта домена]]

## Критерии хорошей ниши на старте

- Много **однотипных вопросов** от клиентов (агент легко закрывает).
- Есть **деньги** и понятная цена потерянного клиента.
- Владелец сам принимает решение (короткий цикл сделки).
- Ты понимаешь их процесс (легче продавать и делать).

## Кандидаты

| Ниша | Почему заходит |
|---|---|
| Салоны красоты / барбершопы | Запись, напоминания, поток однотипных вопросов |
| Стоматологии / клиники | Дорогой лид, много звонков «сколько стоит / когда можно» |
| Онлайн-школы / инфобизнес | Огромный поток вопросов по продуктам и оплате |
| Автосервисы / детейлинг | Запись + предварительная диагностика по вопросам |
| Агентства недвижимости | Квалификация лидов 24/7 |
| Интернет-магазины | Поддержка + допродажи |

> [!tip] Правило
> Выбери **одну** нишу и стань в ней «тем самым, кто делает ИИ-агентов для [ниши]». Кейс в одной нише продаёт следующих клиентов сам.
