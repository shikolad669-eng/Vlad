# Promotion — алгоритмы продвижения бизнеса

Набор переиспользуемых процессов продвижения фитобизнеса в РК. Прогоняется
агентом или Владом. Каждый алгоритм = вход → шаги → выход/метрика. Каналы —
[[phyto/phyto-vault/systems/channels|channels]]; оффер — [[phyto/phyto-vault/systems/wholesale-offer|wholesale-offer]].

## Рамка (читать до любого промо)

- **Два контура:**
  - **B2C — розница:** Instagram [@sibir.kz](https://www.instagram.com/sibir.kz/),
    Kaspi, Flip, розничный отдел, сайт-магазин. Цель — продажи конечнику.
  - **B2B — опт:** привлечение оптовиков. Продвижение опта = магниты + холодный
    выход, дальше передаётся в [[phyto/phyto-vault/systems/lead-gen|lead-gen]].
- **⚠ Юридическая рамка (жёстко, во всех текстах):** продукция — «**не является
  лекарственным средством**». НЕЛЬЗЯ обещать лечение/гарантированный результат,
  ставить диагнозы, называть болезни как «вылечим». МОЖНО: «традиционно
  применяется при…», «для поддержки…», «фитопрофилактика», + «перед применением
  проконсультируйтесь со специалистом». Нарушение = бан карточек на Kaspi/Flip,
  претензии регулятора. Это фильтр каждого поста/карточки.
- **Опорные активы (переиспользуем):** позиция «научная фитотерапия» +
  «женское здоровье»; эксклюзив бренда Гордеева; склад в Караганде; сертификаты;
  ~780 SKU. Дисклеймер несём везде.

## Алгоритм 1. Instagram (@sibir.kz) — контент-движок B2C

Вход: линейка продуктов + темы «женское здоровье / фитопрофилактика».

1. **Контент-столпы (ротация 4 типов), чтобы не быть только витриной:**
   - *Польза/образование* — «травы при… (традиционно)», как заваривать, разбор растения.
   - *Продукт* — карточка SKU: что, кому, как принимать (в рамке дисклеймера).
   - *Доверие* — сертификаты, склад, «эксклюзив Гордеева», отзывы/UGC, лицо-эксперт.
   - *Вовлечение* — вопросы, опросы, «подбор под задачу» → в директ/WhatsApp.
2. **Формат:** Reels (охват) + карусели (сохранения) + Stories (ежедневно, продажи
   + опросы). Reels — приоритет для нового охвата.
3. **Продукт→контент:** брать топ-категории ([[phyto/phyto-vault/catalog/categories|categories]]) —
   женское здоровье, иммунитет, ЖКТ, сон — под сезон/запрос.
4. **Воронка:** пост → интерес → директ/WhatsApp → консультация «подбор» → заказ
   (розничный отдел / Kaspi / Flip).
5. **Выход/метрика:** охват, сохранения, переходы в директ, заказы из Instagram.

## Алгоритм 2. Маркетплейсы (Kaspi + Flip) — SEO карточек B2C

Вход: каталог со всеми полями ([[phyto/phyto-vault/catalog/products-detailed|products-detailed]]).

1. **Карточка:** заголовок с ключом (что + для чего в рамке), фото (Firebase уже
   есть), состав, применение, фасовка, штрихкод. Полнота = ранжирование + доверие.
2. **Ключи:** как ищет покупатель («фиточай от…», «сбор трав…», «мазь …»),
   в рамке формулировок.
3. **Отзывы:** просить у розничных покупателей → рейтинг двигает выдачу.
4. **Цена/акции:** держать конкурентную vs других селлеров категории (мониторить).
5. **Ассортимент:** заводить бестселлеры первыми, расширять по спросу.
6. **⚠ Модерация:** мед-обещания → снятие карточки. Держать рамку.
7. **Выход/метрика:** показы, конверсия карточки, позиция в категории, рейтинг.

## Алгоритм 3. Локальное продвижение (Караганда) — розничный отдел

Вход: физическое присутствие + склад в Караганде.

1. **2ГИС/Яндекс/Google-карточка** отдела: адрес, часы, фото, категории, отзывы.
2. **Гео-таргет** Instagram/локальная реклама по Караганде.
3. **Оффлайн:** вывеска/POS, «подбор трав» как услуга, карта лояльности.
4. **Локальные партнёрства:** банные комплексы, спа, женские студии, ЗОЖ-точки.
5. **Выход/метрика:** трафик в отдел, звонки с карт, локальные заказы.

## Алгоритм 4. WhatsApp / консультация — конверсия и удержание

1. **Вход** со всех каналов: «получить подбор» / «прайс».
2. **Скрипт:** запрос → уточнение задачи → 1–2 продукта в рамке → заказ.
3. **Удержание:** база клиентов, повторные касания (сезон, допродажа курса).
4. **Регламент ответов** (кто, скорость, тон) — завести отдельно.
5. **Выход/метрика:** ответ→заказ конверсия, повторные покупки.

## Алгоритм 5. Сайт travnik.kz — SEO + «готовые решения» + опт-лендинг

1. **SEO:** страницы категорий/товаров под поисковые запросы РК.
2. **«Готовые решения»** (комплекты) — средний чек + простота выбора.
3. **Опт-лендинг** `/optovikam` — магнит «получить оптовый прайс» (см. Алгоритм 6).
4. **Выход/метрика:** органический трафик, заявки, заказы.

## Алгоритм 6. B2B-продвижение опта — магнит + холодный выход

Вход: оффер опта. **Стыкуется с [[phyto/phyto-vault/systems/lead-gen|lead-gen]].**

1. **Магнит:** «оптовый прайс + условия» за контакт (форма `/optovikam`, WhatsApp).
2. **Материалы оптовику:** прайс под сегмент, пакет сертификатов, УТП (склад в
   Караганде, отгрузка в день заказа, растаможено, бух. документы).
3. **Холодный выход:** список из [[phyto/phyto-vault/market/wholesale-leads|wholesale-leads]]
   → скрипт первого касания под сегмент → прайс → сделка.
4. **Витрина доверия для B2B:** кейсы, «эксклюзивный дистрибьютор Гордеева».
5. **Выход/метрика:** заявки на прайс, конверсия в первый заказ, LTV оптовика.

## Алгоритм 7. Threads (@sibir.kz) — текстовый, founder-led B2C (+прогрев B2B)

Вход: та же Meta-учётка, что Instagram (Threads привязан к аккаунту). Формат —
**текст-first, разговорный**. Данные — веб-поиск 2026-07-25 ([[phyto/phyto-vault/sources|sources]]).

**Почему стоит зайти сейчас (окно):**
- РК: **~1,85 млн** пользователей, Threads обогнал X; аудитория ценит «без глянца»,
  личные истории, платёжеспособные 25–45. Глобально ~320 млн MAU (янв. 2026).
- **Реклама запущена глобально 21.01.2026** — все 6 целей Meta (Awareness, Traffic,
  Engagement, Leads, App, Sales); **CPM на 30–40% ниже Instagram** в раннем окне.
- Алгоритм тянет: **ответы > лайки**, свежесть, узкую нишу, разговорность; работает
  **голос основателя/владельца**, а не безличный бренд.

**Шаги:**
1. **Голос от лица владельца / травника-эксперта** (не витрина): личные истории,
   «почему травы», разбор мифов о фитотерапии, закулисье склада/сборов.
2. **Текст-first, провоцирующий ответы:** короткие треды-рассуждения, вопросы к
   аудитории — реплаи двигают охват.
3. **Узкая ниша:** женское здоровье / фитопрофилактика — держать фокус, не распыляться.
4. **Кросс с Instagram по-умному:** одна тема — разные формы (Reels в IG, текст-тред
   в Threads), не тупой кросс-пост.
5. **Тест Threads Ads в дешёвом окне:** цели Leads/Traffic на опт-лендинг и Sales на
   маркетплейс; объявления «как органика», без агрессивных CTA и текста-оверлея.
6. **Воронка:** тред → профиль → Instagram/WhatsApp → заказ (розница) или прайс (опт).
7. **⚠ Юр-рамка та же:** без обещаний лечения (см. Рамку выше).

**Выход/метрика:** реплаи/охват, переходы в профиль, дешёвые лиды из Ads, заказы.

## Общий цикл продвижения

Планировать помесячно по контурам (B2C/B2B) и каналам; вести контент-план
пачками; после периода — снять метрики, вынести что сработало в
[[phyto/phyto-vault/lessons/README|lessons]] (триггер→правило→почему), следующий
период усиливать работающие каналы. **Каждый артефакт проходит юр-рамку** до
публикации.
