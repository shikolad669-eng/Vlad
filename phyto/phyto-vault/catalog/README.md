# catalog/ — ассортимент (снимок 2026-07-24)

Ассортимент бизнеса. **Данные `derived` — источник правды — живой
[travnik.kz](https://www.travnik.kz/catalog).** Здесь снимок на 2026-07-24
(снят из Next.js RSC-потока): цены и наличие устаревают, каноном не считаются.

- **[[phyto/phyto-vault/catalog/products-detailed|products-detailed]]** — полный
  список **780 позиций со всеми полями** (цена, фасовка, форма, штрихкод, страна,
  срок годности, описание, состав, применение, ссылки на страницу/фото/источник),
  сгруппирован по 19 категориям. Это основной каталог-справочник.
- **[[phyto/phyto-vault/catalog/full-catalog|full-catalog]]** — компактный список
  тех же 780 позиций (наименование / фасовка / цена) для быстрого просмотра.
- **[[phyto/phyto-vault/catalog/categories|categories]]** — сводка 19 категорий
  (кол-во + диапазон цен) + замечания по структуре ассортимента.

## Машинные данные (полный дамп)

- `products.csv` — все 780 позиций, все поля, таблично (для Excel / импорта в
  Kaspi / маркетплейс).
- `products.json` — исходный массив со всеми полями (для скриптов/обновлений).

Покрытие полей в снимке: состав — 293/780, применение — 442/780, штрихкод —
671/780 (остальные на витрине не заполнены).

## Как вести

- Обновление цен/наличия — повторным снимком с сайта (RSC-поток `/catalog`),
  с новой датой. Старый снимок не «правится по памяти».
- Оптовые цены сюда **не** класть как канон — они «по запросу», живут в прайсе
  (→ [[phyto/phyto-vault/systems/wholesale-offer|wholesale-offer]] / `secrets/`).
