# cad/ — файлы чертежей

Тяжёлые бинарники: DWG/DXF, STEP/IGES, 3D-модели, экспортные PDF, проекты
CAD-систем. Содержимое **вне git** (корневой `.gitignore`) — трекается только
этот README.

## Правила

- Имя файла/папки — search-hook: `<деталь-или-проект>-<версия>` (напр.
  `flange-bracket-v2.dwg`), не `чертёж-1.dwg`.
- Подпапки (по проектам/деталям, `parts/`, `assemblies/`, `exports/`) **рождаются
  от факта** при первой инвентаризации, не выдумываются заранее.
- Каждому значимому чертежу — карточка-указатель в `../drafting-vault/drawings/`
  (иначе файл потерян для агента): что это, где файл, версия, назначение.
- Бэкап тяжёлых файлов — отдельная забота (git их не хранит).
