# posts/ — опубликованный контент (личный бренд Влада)

Канонический стор постов Влада. Один пост = **бандл-папка**: текст + теги +
журнал публикаций + **ассеты реальными файлами** (чтобы будущий агент мог их
грузить).

> **Структура:** контент-вывод использует **бандл на пост** (одна папка = пост
> + его файлы). Flat-правило остаётся для knowledge-vault; это другая зона —
> деливераблы, не атомы знания, поэтому держим комплект вместе.
> Канон спека — у завода:
> `../../content-factory/content-factory-vault/content-bundle-spec.md`.
> Ниже — локальная копия правил; при расхождении канон у завода.

## Правила записи (спек бандла — локально; канон у завода)

Один пост = одна папка `YYYY-MM-DD-<slug>/`. Внутри:

**1. `post.md`** — единственный текстовый файл, источник правды. Секции в
фикс. порядке:
- frontmatter: `type: post` · `status: draft|ready|published` · `platforms` ·
  `format: photo|carousel|text|video|reel` · `slides` (если карусель) ·
  `tags` · `date`.
- `## Подпись (канон)` — финальный текст подписи + хэштеги, **в одном ` ``` `
  блоке** (копировать целиком).
- `## Раскадровка` — если карусель/видео: нумерованный список
  «роль — суть».
- `## Мета` — локация, @-теги (проверенные), источники фактов.
- `## Ассеты` — манифест: имя файла → что это.
- `## Журнал` — где и когда опубликован.

**2. Ассеты — реальными файлами, предсказуемыми именами:**
`photo-1.jpg …`, `slide-1.png …`, `reel.mp4`.

**3. Чего здесь НЕ держим:** правила создания контента (голос, шаблоны,
форматы) — они живут в charter/workflow/заводе. Здесь только готовые блоки +
их текст.
