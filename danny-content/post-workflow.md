# Post-workflow — как агент-проекция делает пост (пошагово)

Runbook создания поста от материала до готового бандла. Charter = кто я/голос;
routing = куда; **этот файл = что делаю по шагам.** Метод унаследован из
витрины Скандара (проверен на его постах 2026-06/07).

## Железные правила (нарушение = провал)

- **Влад пишет финальный текст сам.** Агент: структура · углы · хуки ·
  полировка · мета · ассеты. НЕ выдаём готовый текст как финал — предлагаем
  каркас, Влад пишет, мы полируем.
- **«Отполируй ≠ перепиши».** Если просят полировку — только
  орфография/запятые/стиль, формулировки не трогаем. Переписываем только по
  явной просьбе.
- **Честность > красоты.** Факты проверяем (веб/источник), НЕ переклаиваем.
- **Ноль инфоцыганства.** Без эмодзи-лесенок, цифр дохода, скорости,
  стрелок-цепочек, дефицита, люкс-понтов, «изменю жизнь».
- **Плейн-текст, без виджетов.** Вопросы Владу — текстом (глобальный инвариант,
  NO AskUserQuestion).
- **Не публикую сам.** Готовлю → показываю → Влад постит. Публикация только по
  команде.

## Шаги

**0. Материал + маршрут.** Взять факт/запись/мысль из любого домена (музыка,
учёба, цех, личное — читаю поперёк по `../CLAUDE.md`). По `routing-table.md`
определить поверхность(и). Провалил фильтр поверхности → не туда.

**1. Структура, не текст.** Предложить каркас: хук (первая строка — до «…ещё»),
2–4 смысловых блока, финал. Для доверия — пруф, не прилагательные. Дать 2–3
варианта угла, Влад выбирает.

**2. Влад пишет драфт → полировка.** Он присылает текст. Полирую
(орфография/запятые/стиль), формулировки сохраняю. Проверяю факты.
Стилистические свопы предлагаю списком «было → стало».

**3. Мета.** Теги @ (проверенные — открыть аккаунт, не вписывать вслепую),
хэштеги (сдержанно, честные теме, без cringe), локация.

**4. Выдача текста.** Финальная подпись + теги — **в ОДНОМ ` ``` ` код-блоке**
(Влад копирует целиком). Не размазывать по комментариям.

**5. Ассеты.** Визуал/монтаж — станками завода
(`../content-factory/content-factory-vault/processes/`); фото/записи — от
Влада. Ассеты кладутся **реальными файлами** в бандл.

**6. Запись в бандл.** `posts/YYYY-MM-DD-slug/` по спеку `posts/README.md`:
`post.md` (подпись + раскадровка + мета + манифест + журнал) + ассеты файлами.

**7. ОБНОВИТЬ КАРТУ (не забыть — иначе следующий агент «не найдёт»).**
- `posts/README.md` → журнал публикаций (пост · формат · статусы · дата).
- `HOME.md` → секцию `## Posts`.
- Урок базы: контент записан, но карта не обновлена → следующий агент поверил
  карте и начал с нуля. **Запись без обновления карты = работа потеряна.**

**8. Публикация.** Отдать Владу: что куда постить, порядок, подпись из
`post.md`. Постит он. После факта — проставить статус в журнале.

## Быстрый чек перед «готово»

- [ ] текст — финал от Влада, я не выдал свой за его
- [ ] факты проверены, ничего не переклаено
- [ ] мета: теги проверены, хэштеги без cringe
- [ ] подпись+теги в одном код-блоке
- [ ] ассеты файлами в бандле
- [ ] `README` журнал + `HOME` `## Posts` обновлены
