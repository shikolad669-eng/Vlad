# Шаблон структуры Discord-сервера (стиль ARUKU)

Переиспользуемая заготовка для заказов: аккуратный костяк «комьюнити-сервер»
с оформлением в стиле ARUKU. Взято с живого сервера ARUKU, обобщено под
универсальный каркас (первое применение — [[discord-custom/discord-custom-vault/tasks/mendeleev-server/log|Сервер Менделеев]]).

## Конвенция названий

- **Категория:** `эмодзи﹕НАЗВАНИЕ` (иногда с хвостом `﹒`). Discord показывает
  капсом. Пример: `🔮﹕информация`, `💿﹕ТЕКСТОВЫЕ ﹒`.
- **Канал:** `эмодзи + разделитель + имя`. Разделители: `・` (katakana middle
  dot) или `︙`. Пример: `📩︙・социальные-сети`.
- **Скобка группы:** внутри категории первый канал — `┏`, средние — `┃`,
  последний — `┗` (визуальная «рамка» сверху вниз). Пример:
  `🔴┏・главное … 🔴┗・розыгрыш`.
- Спецсимволы (unicode): `﹕`=U+FE55, `﹒`=U+FE52, `︙`=U+FE19,
  `・`=U+30FB, `┏`=U+250F, `┃`=U+2503, `┗`=U+2517.

## Базовый каркас (универсальный)

Минимум, без специфики конкретного сервера:

- **информация** — правила, новости, события, главное, набор, розыгрыш.
- **ТЕКСТОВЫЕ** — общий чат, медиа/творчество, тиммейты, корзина/оффтоп.
- **ТЕЛЕПОРТ** (голос) — общая, приватная(ые).
- **трибуна** — обсуждение, голосование, стейдж (если включено «Сообщество»).
- **Уютный уголок** — под-комьюнити: своя инфо/правила/чатик/творчество +
  тематические голосовые клубы.
- (опц.) **TOURNAMENT** — под турниры/ивенты.
- (опц.) **CLOSE** — приватная зона под роли.

## Слои поверх структуры (обычно отдельные этапы заказа)

1. **Роли** — цветные роли, self-assign через reaction-roles (боты MEE6 /
   Carl-bot / Dyno). Ждут стек (см. [[discord-custom/discord-custom-vault/status|status]]).
2. **Права доступа** — приватные категории/каналы под конкретные роли.
3. **Брендинг** — иконка, баннер сервера, эмодзи, картинки-шапки каналов
   (тяжёлые файлы → `../../assets/`, карточка-указатель в vault).
4. **Модерация/автоматизация** — приветствия, тикеты, антиспам (боты).

## Что НЕ копировать у чужого сервера-референса

- **Тексты правил и описаний** — авторский контент чужого сервера; пишем свои,
  под каналы/роли заказчика.
- **Имя чужого сервера** в названиях категорий/каналов.
- Каналы под чужую игровую экономику/специфику, если она не нужна заказчику.
