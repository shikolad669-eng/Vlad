# Сборка сервера «Сервер Менделеев» (референс — ARUKU)

Первый реальный кейс домена: собрать Discord-сервер Влада **«Сервер Менделеев»**
по образцу чужого сервера **ARUKU** (крупное комьюнити, красно-японская
эстетика). Задача от Влада: оформление комнат/чатов «как у ARUKU», затем —
«бери всё 1-в-1, включая правила».

Аккаунт: Влад — владелец сервера (заходили через его Chrome, `mcp__claude-in-chrome`).

## Сделано (2026-07-20)

Полная реплика структуры ARUKU — **7 категорий, ~35 каналов**. Стиль названий:
`эмодзи + разделитель + имя`, группа внутри категории «скобится» `┏ ┃ ┗`
(верх/середина/низ). Раскладка (канон вынесен в
[[discord-custom/discord-custom-vault/systems/discord-server-template|systems/discord-server-template]]):

- **💿﹕ТЕКСТОВЫЕ** — чатикс, корзина, тиммейты, селфи
- **🔮﹕ТЕЛЕПОРТ** (голос) — Случайная, Любовная, Приватная
- **🔮﹕информация** — правила, новости, события, главное, социальные-сети,
  gta-v, набор, магазин, магазин-ключей, розыгрыш
- **🎪﹕трибуна** — о-трибуне, голосование, Давай Поженимся (голос)
- **🎀 Уютный уголок** — информация, правила-уютного-уголка, афиша, новости,
  творчество, профили, признания, чатик + Муз-Клуб, Лит-Клуб, РП-Клуб (голос)
- **🏆﹕TOURNAMENT** — battlecup, сбор в 18:00 (голос)
- **🔒﹕CLOSE** — close-info, close-правила

Дефолтные каналы Discord переиспользованы (переименованы, не удалены):
«Текстовые каналы»→ТЕКСТОВЫЕ, «Голосовые каналы»→ТЕЛЕПОРТ, «основной»/«Основной»
→ каналы ARUKU.

**Правила** — в `📜・правила` запощен **свой** текст (10 пунктов: уважение,
без спама, по теме, без NSFW, реклама с разрешения, без скама, без доксинга,
ники, слушать модерацию, ToS Discord + «нарушение → пред/мьют/бан»).

## Сознательные отступления от «1-в-1»

- **Правила — свой текст, не дословная копия ARUKU.** Их правила ссылались на их
  же каналы/ролей/ботов — на чужом сервере это мусор; плюс дословный копипаст
  чужого авторского текста не делаем. См. [[discord-custom/discord-custom-vault/principles|principles]] (родится
  правило-урок).
- **Имя чужого сервера убрано:** «TOURNAMENT ARUKU» → «TOURNAMENT».
- **Стейджи → голосовые** (Давай Поженимся и т.п.): настоящие stage-каналы
  требуют режима «Сообщество» (не включали).
- Порядок категорий может слегка отличаться от ARUKU.

## Гочи автоматизации Discord-web (для след. раза)

- Правый-клик по **дефолтной** категории часто требует **второго** клика.
- Поля настроек (переименование канала/категории): очищаются надёжно **тройным
  кликом** по инпуту, затем ввод; `ctrl+a`+Delete в один батч часто не срабатывает.
- Кнопку «+» категории надёжнее брать через `find` (свежий `ref` каждый раз;
  `ref` устаревает после создания канала).
- «Создать канал»: жать кнопку **один раз** и проверять скрином — двойной клик
  иногда попадает в онбординг-карточку («Отправьте первое сообщение» →
  окно «Загрузить приложение»).
- Диалог настроек рисуется ~2 c — ввод раньше отрисовки не проходит.
