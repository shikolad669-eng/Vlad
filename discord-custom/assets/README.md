# assets/ — тяжёлая графика заказов

Иконки серверов, баннеры, эмодзи-паки, GIF, макеты оформления. Содержимое
**вне git** (корневой `.gitignore`) — трекается только этот README.

## Правила

- Имя файла/папки — search-hook: `YYYY-MM-DD-<клиент-или-проект>-<что-это>`.
- Подпапки (по клиенту/заказу) **рождаются от факта**, не выдумываются заранее.
- Каждой значимой единице — карточка-указатель в `../discord-custom-vault/`
  (иначе файл потерян для агента).
- Бэкап тяжёлых файлов — отдельная забота (git их не хранит).

Карта домена: [[discord-custom/discord-custom-vault/HOME|HOME]].
