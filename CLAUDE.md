# vlad — верхний уровень (карта неймспейса)

`~/vlad/` — **верхний** уровень (level) личного неймспейса Влада: meta-vault
(`vlad-vault`) + домены + проекции, всё в одном репозитории. Это папка-контейнер,
не один проект. Терминология — `vlad-vault/glossary.md`.

Неймспейс рождён 2026-07-10 как зеркало неймспейса Скандара (`~/skandar/` на его
машине): **идентичная структура — главное условие**, потому что два неймспейса
часто синхронизируются. Метод (шаблоны, глоссарий, принципы) скопирован из базы
Скандара; наполнение — Влада.

Финальная цель — **LLM-независимое хранилище**: данные = читаемый markdown,
переживающий любой инструмент. Движок/клиент выкидываемо-переписываем; данные
остаются. `~/.claude/` — сменный кэш клиента, **не** источник правды.

> **Invariant (all levels):** NEVER `AskUserQuestion` / popup choice dialogs —
> questions always in plain text. Communication principles: `vlad-vault/preferences.md`.

## Уровни неймспейса (иерархия)

`~/vlad/` (корень) — верх: доступ ко всему, связи вниз через `vlad-vault`
(meta-vault). Ниже — домены, каждый в своём scope:

- **личное:** `vlad-life/` — живой первоисточник (дневник). `trust: primary`.
- **работа:** `music/` (музыка), `study/` (учёба), `drafting/` (чертежи),
  `phyto/` (бизнес: оптовая фитопродукция, дистрибуция трав Гордеева по РК),
  `content-factory/` (цех контента), `discord-custom/` (бизнес: заказная
  кастомизация Discord), `ai-agents/` (бизнес: ИИ-агенты для бизнеса под ключ).

**Иерархия, не демократия:** top-агент пишет во все уровни ниже; нижние
горизонтально друг другу не пишут. Работая в нижнем уровне, агент подчиняется
**локальному** `CLAUDE.md` этого уровня.

## Оркестратор (агент этого уровня)

Имя агенту верхнего уровня не присвоено (2026-07-10). Имена агентов уровней ниже
(рабочие, унаследованы из неймспейса Скандара): **Денни** (danny-content — личный
контент-исполнитель), **Завод** (content-factory — цех). Реестр:
`vlad-vault/glossary.md` → «Имена агентов».

- **Governance** — пишет вниз во все уровни; нижние горизонтально не пишут.
- **Навигатор (read-mode)** — не знаешь, куда идти: спускается по уровням, находит
  дверь, маршрутизирует. Без записи.
- **Диспатч** — вызывает уровневых агентов как воркеров, **всегда с планом,
  который Влад читает** до запуска.
- Контент **не** производит: витрина — `danny-content/` (Денни). «Сделать
  контент» → диспатч Денни или старт в его папке.

## Ось доверия

`trust` — метаданное первого класса. Граница папок = граница доверия.
Тест: **«я это написал/проверил — или ИИ надстроил поверх и я не глядел?»**

| Род | trust | Регенерируется? | Дом |
|---|---|---|---|
| Первоисточник | `primary` | нет (незаменимо) | `vlad-life/` |
| Производное ИИ | `derived` | да | (зоны появятся при надобности) |
| Движок (код+индекс) | — | версионируется в git | (не подключён; RAG отложен) |

## Раскладка `~/vlad/`

- `CLAUDE.md` — эта дверь (карта неймспейса).
- `vlad-vault/` — meta-vault: метод, решения, связи вниз ко всем доменам.
  Старт — `HOME.md`.
- `vlad-life/` — **первоисточник** личного: `diary/`, `inbox/`, `texts/`.
  `trust: primary`, `sensitivity: private`; содержимое дневника — вне git.
- `music/` — домен музыки: своя дверь + `music-vault/` + `media/` (файлы музыки,
  вне git).
- `study/` — домен учёбы: своя дверь + `study-vault/`.
- `drafting/` — домен чертежей: своя дверь + `drafting-vault/` + `cad/` (тяжёлые
  файлы чертежей DWG/STEP/PDF, вне git).
- `phyto/` — **бизнес** оптовой фитопродукции: своя дверь + `phyto-vault/`
  (LLM-вики). Эксклюзивный дистрибьютор трав Гордеева по РК, склад — Караганда;
  витрина travnik.kz + Instagram @sibir.kz (2026-07-24).
- `discord-custom/` — **бизнес** заказной кастомизации Discord (сервера, боты,
  брендинг, модерация): своя дверь + `discord-custom-vault/` (клиентский:
  `clients/` + `positioning.md`) + `assets/` (тяжёлая графика, вне git).
- `ai-agents/` — **бизнес** ИИ-агентов для бизнеса под ключ (внедрение + подписка
  на обслуживание): своя дверь + `ai-agents-vault/` (оффер, клиенты, база лидов
  Караганды, LLM-вики). Заведён 2026-07-27 слиянием отдельного волта «Влад
  бизнес» в неймспейс; первый оплаченный клиент — Татьяна.
- `content-factory/` — **цех** контента (агент Завод): процессы, станки, intake
  сырья. Зеркало `maksi-content-factory` Скандара; канон живого венчура — у него.
- `danny-content/` — **проекция** личного бренда (агент Денни): дверь + карта,
  **без vault**; читает домены по этой карте, пишет на поверхности.
- `public/` — проекция «наружу»: готовые внешние артефакты. Безагентная.
- `documents/` — приёмник документов (вне git; аналог parked-архива у Скандара).
- `secrets/` — доступы (вне git, NEVER commit/sync/index; контракт в README).

## Границы

- Не переименовывать уровни и не переписывать их git-историю.
- Секреты только в `secrets/` / `.env`, никогда в трекаемых файлах — только
  указатели (`vlad-vault/secrets-map.md`).
- Репо — приватный GitHub `skandar11/vlad`, доступ Владу — коллаборатором
  (2026-07-10). Личное (дневник, inbox), медиа, документы и секреты в git не
  попадают по построению (`.gitignore`).
- Тяжёлые файлы (музыка, видео, документы) живут в своих папках вне git;
  в vault — карточки-указатели.

> Канон структуры: `vlad-vault/vault-template.md` (база-баз) +
> `vlad-vault/entry-points.md` (двери/карты). Обзор одной страницей:
> `vlad-vault/meta-map.md`.
