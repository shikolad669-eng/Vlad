# content-bundle-spec — единый стандарт контент-единицы

Один стандарт для **всех витрин** (danny-content, академия, будущие), чтобы контент
находился предсказуемо и агенты (включая автопостинг завода) читали его одинаково.
Обобщение спека `~/vlad/danny-content/posts/README.md` (решение бандла 2026-06-29);
владелец спека — завод (спек = процессный артефакт).

## Принцип

**Одна единица контента = одна папка-бандл** `YYYY-MM-DD-<slug>/` в конюшне своей
витрины-владельца:

- личный бренд → `~/vlad/danny-content/posts/`
- образование → `~/skandar-academy/content/`

Деление — по **владельцу смысла**, не по платформе. Поверхность (IG/TG/Habr/YouTube) —
**метаданное бандла, не папка**: пост на три поверхности = один бандл с тремя строками
журнала, не три копии.

## Внутри бандла

**1. Текстовый источник правды** — один `.md` (у постов `post.md`; у рилса — сценарий
тем же файлом). Frontmatter:

```yaml
type: post | reel | carousel | article
status: draft | ready | posted
surface: [имена из ~/vlad/vlad-vault/surfaces.md]
format: photo | carousel | text | video | reel
date: YYYY-MM-DD
tags: []
```

Секции (фикс. порядок, лишние опускаются):
- `## Подпись (канон)` / `## Сценарий` — финальный текст **одним ``` блоком** (копировать целиком);
- `## Раскадровка` — слайды/кадры: `роль — суть`;
- `## Мета` — локация, @-теги, источники фактов;
- `## Ассеты` — манифест: имя файла → что это;
- `## Журнал` — куда/когда опубликовано + ссылка.

**2. Ассеты — реальными файлами, предсказуемые имена:** `photo-1.jpg…`, `slide-1.png…`,
`reel-final.mp4`, `cover.jpg`. Экспорт-файлы кладутся в бандл (исходники остаются в
инструменте — Claude Design, монтажка); файлы нужны, чтобы автопостинг грузил напрямую.

**3. Чего в бандле НЕ держим:** процессные знания (как делать) — они живут здесь,
в заводском vault; голос/routing — у витрины.

## Статусная машина (контракт с автопостингом)

`draft` → `ready` (готов к публикации, ассеты на месте) → `posted` (+ дата и ссылка
в `## Журнал`). Автопостинг завода берёт только `ready`, после публикации проставляет
`posted`. Публикация без команды Скандара запрещена.

## Витринам

Локальные README конюшен (`posts/README.md`, `content/README.md`) держат журнал и
локальные особенности, но **спек не переопределяют** — при расхождении канон здесь.
