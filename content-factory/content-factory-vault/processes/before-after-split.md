# Пайплайн-кандидат — «before-after split»

**Статус: кандидат, 0 прогонов (бэклог).** Освоенный формат из чужого разбора
(`~/maksi-content-factory/intake/ref/2026-07-06-higgsfield-omni-flash/teardown.md` (машина Скандара; ref-сырьё не копировано), Higgsfield
Omni Flash). Пока не прогнан своими руками — при первом прогоне правила подтверждаются
и, если формат приживётся, канон складывается в [[content-factory/content-factory-vault/processes/video-station|video-station]] как формат-обёртка над
любым треком. До прогона живёт отдельным кандидатом, чтобы не мешать проверенный канон.

## Идея

Формат-обёртка, ортогональная трекам A–D: показать **любую нашу трансформацию против
оригинала** синхронным сплитом. Верх = обработанный кадр (генеративка трека A / VFX
трека C), низ = исходник; между ними — жёлоб с караоке-сабами; сверху — бренд-хедер.
Зритель видит ровно что сделал эффект.

## Раскладка (720×1280 / 1080×1920, 9:16)

```
[ бренд-хедер PNG, приколот весь ролик ]
[ ВЕРХ: обработанный кадр, letterbox 16:9 ]   ← чип "AFTER"/название эффекта
[ центр-жёлоб: караоке-сабы 2–4 слова ]
[ НИЗ: исходный кадр, letterbox 16:9 ]         ← чип "ORIGINAL"
```

## Сборка — наш стек (проверенные кубики станции)

Всё из общего слоя [[content-factory/content-factory-vault/processes/video-station|video-station]], нового движка не требует:

- **Сплит:** два синхронных клипа → `vstack` (или `xstack` с чёрным жёлобом-полосой
  между). Оба тримить к одной шкале — рассинхрон = тихий брак (чек длительности из станции).
- **Чипы/хедер:** PNG-плашки (Pillow, дизайн-система maksi) — приколоть `overlay`;
  хедер не мигает, чипы в левый-верх каждой панели.
- **Караоке-сабы:** `gen_subs.py` → ASS → фильтр `ass=`, тайминги из word-timestamps;
  CUTS — единственный источник правды (правило станции).
- **Звук/экспорт:** общий слой станции (loudnorm, faststart, crf 23 preset slow).

## Что даёт формат

1. Наглядность трансформации (главная ценность — виден вклад эффекта).
2. Темп: паттерн «каждый бит спавнит новое» держит внимание (грабля-хук из teardown-01).
3. Ростовая петля: comment-CTA («COMMENT "X" TO GET…») в тело + энд-кард.

## Первый прогон — задача (бэклог)

**Сделать такое видео самим** на нашей трансформации (кандидат-сырьё — выход трека A
Veo или трек C VFX; исходник — запись Скандара из `../../intake/raw/`). Цель прогона —
освоить формат, не изобрести свой. Метод: [[content-factory/content-factory-vault/principles|principles]] — сначала учимся у других,
потом придумываем своё. После прогона — дельта правил сюда / в [[content-factory/content-factory-vault/processes/video-station|video-station]].
