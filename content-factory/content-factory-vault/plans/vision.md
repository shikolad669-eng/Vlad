# Vision — content-factory

Concept and horizon. **MVP and pipeline mechanics are explicitly not now** (Skandar's
call: this session is strategy/concept only). This file fixes the concept so it is not
lost and frames the deferred work.

## Why now (the demand thesis)
Brands, restaurants, and local businesses already flood Adil with offers for SMM /
reels / promotion. He **drops most of it on the floor** — does only what interests him,
holds nothing. The venture captures that **overflow demand**: it is "pick up what is
already falling", not "build and hope". Demand exists *before* the build, which flips the
risk profile.

## The pipeline (concept only — 7 stations)
Not a build spec — the shape, for orientation. Detailed tooling is a later session.
1. Brief → **per-client knowledge base** (the grounding layer / moat).
2. Ideation + scripts from the client base + trends + **Adil's own viral formats** as templates.
3. Production in three tiers: (a) Adil personally, (b) **templated-Adil** (modular real
   clips + AI voice/script reskin per client), (c) pure AI video.
4. Edit (auto-cut, captions, music, client branding overlay).
5. Copy / captions / hashtags, grounded in the client base.
6. Scheduling / posting.
7. Feedback loop — pull numbers, feed back to station 2.

## Build discipline (deferred, but recorded)
- **Do not build the factory before a paying client.** Take ONE real inbound brand,
  deliver semi-manually, systematise only what repeats (per
  `~/skandar/skandar-vault/plans/company-bootstrap.md` (машина Скандара) discipline). The pipeline
  earns the right to exist after ~3 manual deliveries.
- **Build hand = Vlad (candidate) or another** — once taught / bought in.

## Research threads (test before promising clients)
- **Templated-Adil tech.** Voice clone + lip-sync onto real footage with new script /
  branding is production-grade today; **full synthetic Adil is rejected for MVP** — brand
  risk to his face-as-asset + uncanny valley. The realistic version reskins script /
  voice / captions / branding over real modular clips. Needs hands-on testing.
- **Auto-rebrand per restaurant** — logo/colors/lower-thirds/menu as template editing
  (automatable); face stays real footage.

## Open (for the deferred working session)
- What exactly the **demo-MVP** is that convinces both the first restaurant and Adil.
- Which station is the real labour bottleneck (automate that one first).
- Tooling per station (voice clone, lip-sync, edit, generation).
