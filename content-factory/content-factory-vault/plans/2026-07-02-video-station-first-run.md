# Первый прогон видео-станции — запись семинара 5.07

Локальный план завода из стратегической сессии 2026-07-02 (skandar-уровень).
Самодостаточен для агента этого домена.

**Рамка:** домен остаётся concept-stage. Это НЕ «строить фабрику» — это первая
полуручная поставка по build-discipline из [[vision]] (поставить руками,
систематизировать только то, что повторяется). Станции 3–4 из vision получают
первый реальный прогон.

## Вход

- Длинная запись (~3ч) семинара академии 5 июля — поступает **сверху**
  (диспатч skandar-уровня), не напрямую из соседнего домена.
- До 5.07 — тренировочный прогон на любом длинном видео (материал есть,
  подойдёт любой запис/подкаст).

## Задача: длинная запись → пачка рилсов

1. **Транскрипт с таймкодами** — локально, mlx-whisper (у Skandar есть команда
   `transcribe`).
2. **Выбор сильных моментов** — LLM по транскрипту (критерии: законченная мысль,
   хук в первые 2 сек, 30–60 сек).
3. **Нарезка + кадрирование 9:16** — ffmpeg.
4. **Сабы** — из того же транскрипта (жечь в кадр или .srt — решить на прогоне).

## Второй трек: картинки (добавлено 2026-07-02)

Контент-пайплайн — не только видео: **посты/карусели из картинок** тоже нужны
(первый потребитель тот же — инст макси-академии, диспатч сверху). На
skandar-уровне уже существует рендер каруселей (Claude Design → Playwright, у
blog-проекции) — не дублировать, запросить наверх. Здесь фиксировать по ходу,
что повторяется, — станция картинок систематизируется по тому же
build-discipline, что и видео.

## Генеративный трек: модели и API (добавлено 2026-07-03)

Место фиксации: **завод** хранит station-level решения по ИИ-видео; академия
хранит run-data конкретных роликов (например,
`~/skandar-academy/content/reels/reel-01-clone-jutsu/pipeline-notes.md`).

Принцип: если у владельца модели есть нормальный прямой API, станция идёт
**напрямую к модели**, не через агрегатора. Агрегаторы нужны только как быстрый
полигон, fallback или обход, когда прямого доступа нет / он слишком тяжёлый по
региону, биллингу или enterprise-доступу.

Кандидаты движков:

1. **Google Veo / Gemini API** — основной первый direct-адаптер, потому что
   текущий ручной опыт уже на Google Flow + Veo. Проверить отдельно: Flow credits
   и API-биллинг разные; UI-фичи Flow (персонажи / ingredients / scene builder)
   могут не совпадать 1-в-1 с API.
2. **Seedance 2.x** — обязательный второй кандидат для теста: strong fit под
   reels, anime/high-motion, дешёвые/быстрые итерации и CapCut/Dreamina-ручной
   контур. Проверить прямой ByteDance/Volcengine API под наш регион/биллинг.
   Если прямой доступ открыт без enterprise-боли — ставить рядом с Veo, не после
   него; если нет — использовать через агрегатора только как fallback/benchmark.
3. **Luma Ray** — кандидат для cinematic/keyframe/video-to-video/reframe задач.
4. **Runway** — полезен для editing/video-to-video и как полигон; когда через
   Runway вызывается чужая модель (Veo/Seedance), это уже агрегаторский путь, не
   direct-first.
5. **OpenAI Sora** — не закладывать в основу нового пайплайна: web/app уже
   закрыты, API имеет sunset 2026-09-24.

Целевой интерфейс станции: один adapter layer вида
`generateVideo(prompt, refs, aspectRatio, duration, engine)`, где `engine` =
`veo`, `seedance`, `luma`, `runway` и т.п. Ключи только в env/secret-store;
в tracked files — только имена переменных и инструкции без секретов.

## Страховка (параллельный путь)

SaaS-нарезка: Opus Clip / Klap / Vizard — тест за Skandar (нужен аккаунт).
Главная проверка — качество русских субтитров.

Research 2026-07-04 ([[../research/2026-07-04-agentic-montage-frameworks]]):
у всех трёх публичные API, русский заявлен (реально ~85–95% по community —
ручной проход остаётся). Порядок пилота: **Klap API** (pay-per-op ≈$16 разово;
⚠️ проверить лимит длительности) → **Vizard** (free 60 мин с вотермаркой на
проверку RU-сабов; API на любом платном; 600 мин/видео — 3 ч лезет) →
**OpusClip Pro** ($29, плагин opus-skills для Claude Code; ⚠️ конфликт доков
API-на-Pro; consumer-планы могут учиться на контенте — ToS до аплоада
несмонтированного семинара). Локально не хватает только auto-reframe с
трекингом лица (закрывается MediaPipe из трека C канона).
