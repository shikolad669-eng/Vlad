# Method — стримы, контракт, гейты, чекпоинт, субагенты

Агентская механика **любого** видео-пайплайна цеха. Конкретный порядок — в content-type (`content-type/`);
здесь общий слой. Ремесленные пороги/цифры — [[../../processes/video-station]].

## Стримы (дорожки конвейера)

Пайплайн = набор стримов; одно видео сквозь них = **flow**; гонит Денни = **orchestrator**.

- **prep** — транскрипт, кадры/окна (голова базовая, от неё ветвится).
- **visual** — плашки (рендер) + трекинг головы + контраст-гейт → инфографика.
- **subs** — вербатим-сабы из word-timestamps.
- **audio** — чистка по профилю источника + универсальный экспорт-мастеринг.
- **cover** — обложка (тонмап + плашка maksi).
- **text-meta** — подпись + теги.
- **assembly** — сборка (барьер: visual + subs + audio) → экспорт.
- **qa** — гейты + визуальная проверка.

**Что параллельно:** после `prep` идут `audio ∥ subs ∥ cover ∥ text-meta`; `visual` ждёт короткий
ручной выбор тезисов. Барьер один — `assembly`. Wall-clock ≈ max(ветки) + assembly, не сумма.

## Контракт ручное/авто

- **Авто (скрипты, LLM-агент НЕ нужен):** transcribe, head_track, render_plates, contrast, subs,
  audio, build, export, cover, числовые гейты.
- **Ручное (Скандар, глазами):** выбор дублей/кадров, музыка.
- **Черновик агента → Скандар финалит** (show-then-fix, см. чекпоинт): **текст поста · название в
  кавере · текст инфографики**.

## Четыре код-гейта

Грабли, зашитые в код — не вернутся из прозы. Каждый = ошибка, получившая отзыв, теперь проверяется
машиной. Пороги — в [[../../processes/video-station]]; здесь имя и суть.

1. **контраст-структурный** — мерить текст↔подложка на **ярчайшем** кадре окна; не прошёл floor →
   поднять непрозрачность/скрим **до** сборки. (`contrast.py`)
2. **рендерер-общий** — плашки и обложка **одним** `maksi_plate`, НЕ переписывать из прозы. (импорт, не копия)
3. **тонмап-первым** — HLG→SDR **до** наложения плашек; цвет судить по закодированному mp4. (`assembly`)
4. **аудио-экспорт-стерео** — **всегда стерео** + −14…−16 LUFS + TP −1; проверять **L/R RMS равны**
   (no one-ear). Баг воркшопа 2026-07-06: моно/−20 → «проблемы со звуком». (`audio`, `astats`)

## Review-чекпоинт (show-then-fix)

Перед статусом `ready`: Денни собирает драфт со своими «предложениями» по трём контентным выходам
(пост · название в кавере · текст инфографики) и показывает Скандару **реальные артефакты** (рил +
кавер + подпись). Скандар правит → Денни пере-гоняет **только дешёвые задетые шаги** (пере-рендер
плашек/кавера, правка подписи), не пере-собирает всё. Не пре-гейт «спроси до», а «покажи
сделанное → поправим».

## Субагенты — только на суждении

Параллелить скрипты ≠ плодить LLM-агентов (X4, over-engineering из meta-backlog). Независимые ветки =
параллельные **subprocess** под Денни, без LLM.

- **Денни** = orchestrator (гонит content-type).
- **LLM-субагенты** (параллельны, где суждение): **text-meta** (каркас подписи + честные теги) ·
  **plate-copy** (опц.: тезисы → текст плашек «предложением») · **verify/QA** (опц.: смотрит кадры в
  окнах плашек + обложку сверх числовых гейтов).
- Для talking-head агентов **мало**; тяжёлая параллель — subprocess. Агентная параллель
  (moment-selection веером по клипам) вырастает в `long-cut`/VO — там слот.
