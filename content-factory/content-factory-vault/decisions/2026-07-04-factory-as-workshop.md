# Завод = цех: рабочая роль — процессы контента Скандара

Решение Скандара 2026-07-04 (сессия «стартовые точки контента»). Снимает путаницу
«с чего начинать видео/контент»: цех не создаётся как новая сущность — **им становится
завод**.

## Что решено

**Рабочая роль завода — цех (мастерская) контент-производства Скандара:**

- **Процессы** — *как* делаем видео, *как* делаем дизайн: пайплайны, грабли, нормы
  жанра, экономика. Сюда пишутся процессные знания (видео-станция, дизайн, рендер).
- **Станки** — инструменты производства (vfx-pipeline, ffmpeg-тулчейн, транскрипция,
  Playwright-рендер каруселей). Съезжают сюда из витрин отдельным шагом — станок
  отлаживается один раз и обслуживает все витрины.
- **Intake** — единый **склад** сырья: `../intake/` (см. README там).
  `inbox/` (неразобранное) → `raw/` (записи Скандара, **trust: primary**, не удалять) +
  `gen/` (ИИ-генерации, derived, перегенерируемо). **Точка сброса для Скандара — не
  здесь** (уточнение 2026-07-04): кидает куда близко (`~/skandar-academy/_inbox/`,
  корень рабочего уровня); перенос на склад — работа агента.
- **Автопостинг** — публикация в TG/IG/куда угодно по `ready`-бандлам. Базис —
  [[../tools/telegram-channel-bot]].
- **Спек бандла** — завод владеет единым стандартом контент-единицы:
  [[../content-bundle-spec]]. Витрины (danny-content, академия) применяют.

**Чем завод НЕ является:** витриной. Смыслом, голосом и routing владеют витрины
(`~/vlad/danny-content/` — Денни, личный бренд; `~/skandar-academy/` — образование).
Завод — подрядчик: берёт бриф/сырьё, отдаёт ассет в бандл витрины. Агент завода —
мета-уровень автоматизации конвейера, голоса не имеет.

## Судьба shared-венчура (Адиль)

Концепт «AI-pipeline SMM на дистрибуции Адиля» **паркуется, не удаляется**: positioning,
market, synergy-записи остаются как законсервированная ветка. Пока «про других не
говорим» (Скандар, 2026-07-04) — завод работает как личный цех.

**Условие на будущее:** если венчур размораживается и завод становится реально shared —
личное сырьё Скандара (`intake/raw/`, trust: primary) **выносится из завода** до
предоставления доступа кому-либо ещё.

## Процесс целиком (для понимания, где что)

```
Скандар скидывает (raw видео, голосовые, генерации) → intake/inbox/
  → разбор → raw/ (primary) + gen/ (derived)
  → job: материал + бриф (тема, витрина, поверхность из ~/vlad/vlad-vault/surfaces.md)
  → станки: транскрипция / монтаж / рендер
  → ассет → бандл витрины (по content-bundle-spec) → текст пишет агент витрины
  → status: ready → (авто)постинг по routing витрины → status: posted + журнал
```

## Обратимость

Обратимо: роль переописывается в этой записи и двери; Адиль-ветка лежит рядом
нетронутой. Физических переездов данных решение не требует (кроме будущего выноса
raw при shared).
