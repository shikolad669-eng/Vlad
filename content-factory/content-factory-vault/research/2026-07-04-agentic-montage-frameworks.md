# Агентские монтажные каркасы — research 2026-07-04

Два web-прогона (локальные каркасы; hosted/agent-native), все статусы проверены
по первоисточникам 2026-07-04. Вопрос: чем заменить императивный bash в сборке
(декларативный таймлайн, который агент эмитит и рендерит) и где hosted реально
бьёт локальный стек. Рамка: локальный стек бесплатен и работает — hosted
получает место только если явно выигрывает.

## Вердикт коротко

1. **Кандидат №1 на декларативный слой — auto-editor, формат `.v3`** (JSON-таймлайн
   в обе стороны: экспорт И рендер). Это «CUTS-массив как JSON» почти дословно.
   ✅ **Пилот пройден в тот же день** (пересборка meta-montage: ±1 кадр с
   bash-эталоном, звук идентичен; run-data
   `~/skandar-academy/content/2026-07-04-reel-meta-montage/work/pilot-v3/notes.md`).
   Оба варианта сохраняются до доп прогонов (решение Скандара).
   ⚠️ Грабля установки: brew-зависимость тянет slim ffmpeg и перелинковывает
   поверх ffmpeg-full — см. канон станции, секция «Стек».
2. **Сабы: перестать писать ASS руками** — mlx-whisper JSON → stable-ts
   (`to_ass(karaoke=True)`) или свой генератор на pysubs2. Рендер остаётся libass.
3. **Паттерн на портирование:** EDL-как-контракт + цикл самопроверки (рендер →
   кадры на границах катов → автокоррекция ≤3 итераций) из video-use.
4. **Hosted почти нигде не выигрывает.** Единственный класс с кейсом — нарезка
   длинного видео (семинар 3 ч): Klap / Vizard / OpusClip, у всех публичные API,
   русский заявлен. Рендер-SaaS и ffmpeg-MCP-серверы — мимо.

## Локальный декларативный слой

### auto-editor — брать на пилот (трек B, потом A)

- v31.1.2 (2026-07-03), релизы еженедельно; переписан на Nim; **brew** (arm64
  bottles), с pip ушёл. Лицензия **Unlicense (public domain)** — ноль вопросов.
- **`.v3` = JSON non-linear timeline**: sources, дорожки, per-clip
  `offset/start/dur`, speed, volume, overlay-слои. `--export v3` эмитит,
  `auto-editor cut.v3 -o out.mp4` рендерит. Наша логика катов (whisper words ×
  silencedetect) остаётся нашей — агент считает диапазоны и эмитит JSON вместо
  bash; стабилизация/ASS/обложки остаются в ffmpeg-шагах вокруг.
- Экспорт таймлайна в Premiere/Resolve/FCPX/**OTIO** (с v31.0.0) — бесплатный
  запасной выход в человеческий NLE.
- Встроенный whisper.cpp (сабкоманда `whisper`, `--prompt`-биасинг) — есть, но
  наш транскрипт остаётся mlx-whisper (флаг: словарь/формат word-JSON сабкоманды
  не проверен по докам, только по release notes).
- Композитинг проще filter_complex — для трека A (переходы/мультитрек) может
  стать тесно → тогда резерв MLT.

### MLT XML + melt — резерв для трека A

v7.40.0 (2026-06-25), LGPL, brew arm64, 25 лет истории (движок Shotcut/Kdenlive).
Честный декларативный XML-таймлайн (producers/playlists/tractors), настоящие
переходы (luma/affine), мультитрек. Цена — свой словарь фильтров (≠ ffmpeg).
Пробовать только если v3-композитинга не хватит.

### Сабы (word-pop ASS из whisper JSON)

- **stable-ts** — принимает mlx-whisper как бэкенд и **готовый JSON без
  ре-транскрипции**, `to_ass(karaoke=True)`. ⚠️ Архивирован 2026-05-30 —
  использовать как замороженный leaf-компонент или выдрать ASS-writer.
- **pysubs2** — жив (1.8.1, 2026-03-19), MIT; чистый кирпич для своего генератора
  (полный контроль `\k`/`\t`, UTF-8/кириллица ок). Референс стилей —
  `build_ass.py` из clipify (MIT).
- WhisperX — только если тайминги mlx-whisper окажутся слабы для word-pop; иначе
  второй ASR-стек ни за чем.
- Ничего лучше «генерированный ASS + libass» для кириллицы в 2026 нет — наш слой
  уже правильный, апгрейд только в генерации.

### Паттерн-доноры (читать, не тащить зависимостью)

- **video-use** (browser-use, MIT, 04.2026) — транскрипт → LLM эмитит EDL →
  ffmpeg → **self-eval цикл** (проверка кадров на границах катов, ≤3 итерации).
  Дефолтный STT облачный — заменяется на mlx-whisper, дизайн ложится 1:1.
- **OpenMontage** (AGPL, 03.2026, ~33k звёзд за 3 мес) — YAML-манифесты
  пайплайна + quality gates; читать для идей, строить на нём соло-пайплайн —
  нет (AGPL, огромная поверхность, 3 месяца от роду).
- **clipify** (MIT, 05.2026) — Claude-Code-скилл «длинное видео → 9:16 клипы»
  с face-tracking reframe и whisper→karaoke-ASS; single-drop репо — донор кода
  (build_ass.py, reframe).

### НЕ брать (локальное)

editly (спит с 05.2025, RC-релиз), FFCreator (спит с 12.2024), vidpy (мёртв),
MoviePy для сборки (кадры через numpy — на порядки медленнее `-c copy`;
для frame-ops можно), Diffusion Studio core/agent (браузер в рендер-пути, agent
заброшен с 02.2025), unsilence/videogrep (вытеснены), json-to-ffmpeg (мёртвый
эксперимент), OTIO как источник правды (спека без рендера; получаем бесплатно
из auto-editor при нужде), Remotion как таймлайн (React+Chromium ради того, что
ffmpeg уже делает; фри-тир соло ок — вернуться ТОЛЬКО если понадобится
моушн-графика сверх ASS+Pillow; есть официальный skill-pack для Claude Code).

## Hosted / agent-native

### ffmpeg-MCP-серверы — категория мимо

Все — тонкие обёртки, сужающие агента до предвыбранных тулзов. Claude Code +
Bash + ffmpeg строго лучше. В реестре коннекторов Anthropic видео-редакторов
ноль (проверено 2026-07-04).

### Рендер-API SaaS — мимо

Shotstack ($0.30/мин PAYG) / Creatomate (~$41+/мес) / json2video / Plainly —
реплицируют локальный ffmpeg за деньги с **меньшим** контролем сабов, чем libass.
На 10–30 роликов/мес выигрыша нет.

### Нарезка длинного (семинар 5.07) — единственный живой кейс

Что покупаем: батч-выбор моментов из 3 ч + **auto-reframe 9:16 с трекингом
лица** + капшены одним проходом. Локально нет только auto-reframe (добивается
MediaPipe — движок уже есть в треке C). Русские сабы по community-данным
~85–95% (OpusClip, vc.ru) — ручной проход остаётся при любом варианте.

Порядок пилота (тест за Скандаром — аккаунт/оплата/приватность):

1. **Klap API** — pay-per-op без подписки: ~$0.44 вход + $0.80/шорт ≈ **$16
   разово** за ~20 рилсов. ⚠️ Проверить лимит длительности на API-пути (web-планы
   капают 45 мин/2 ч — 3 ч не лезет).
2. **Vizard** — API на любом платном (~$15–30/мес), `lang: ru` явно в API,
   **600 мин/10 ГБ на видео** — семинар в один вызов; free 60 мин с вотермаркой
   для проверки качества русских сабов до оплаты.
3. **OpusClip Pro $29/мес** — сильнейший продукт + **официальный Claude-Code
   плагин opus-skills** (клиппинг из агента). ⚠️ Конфликт доков: API на
   Pro(Beta)/Max или только Business — проверить при регистрации; кап 15 ч/мес;
   **consumer-планы могут учиться на контенте** — для несмонтированного семинара
   читать ToS.
- Descript — **русской транскрипции нет** (только латиница) — мёртв для нас,
  несмотря на новый API/Underlord (05.2026).
