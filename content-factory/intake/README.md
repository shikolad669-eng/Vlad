# intake/ — склад сырья (после разбора)

Единый склад записанного и нагенеренного. Содержимое всех подпапок **вне git**
(корневой `.gitignore`) — трекаются только README.

**Влад сюда не ходит руками** — перенос и разбор ведёт агент (Завода или тот,
кто разбирает).

## Раскладка

(двери подпапок: [[content-factory/intake/inbox/README|inbox]] · [[content-factory/intake/raw/README|raw]] · [[content-factory/intake/gen/README|gen]] · [[content-factory/intake/ref/README|ref]])


- `inbox/` — неразобранное: стащено с точек сброса, ещё не разложено.
- `raw/` — после разбора: **записи Влада** (видео, аудио). `trust: primary` —
  незаменимо, **не удалять**.
- `gen/` — после разбора: ИИ-генерации. `trust: derived` — перегенерируемо.
- `ref/` — **чужие референсы** (учебное сырьё). study-only, на поверхность не
  идёт; храним текст разбора, файл — кэш.

## Состояния материала

1. **в `inbox/`** — не разобрано;
2. **разобрано** — в `raw/`/`gen/`, ждёт работу;
3. **в работе** — привязано к брифу (тема + поверхность из
   `~/vlad/vlad-vault/surfaces.md`); результат уходит **бандлом в витрину**
   (`~/vlad/danny-content/posts/`) по
   `../content-factory-vault/content-bundle-spec.md`;
4. **отработано** — исходник остаётся здесь (raw — навсегда, gen — можно чистить).

Витринные агенты (Денни) intake **читают**, разбирают в него не пишут.
