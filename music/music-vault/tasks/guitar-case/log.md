# Кейс для гитары — лог сессии 2026-07-10

материалов. Материал — берёзовая фанера.

1. **Уточнена модель:** Fender **California Debut Redondo CE** (Sunburst) —
   дредноут **с вырезом (cutaway)**, голова как у **Stratocaster**. Влад дал
   правки по форме; подтверждено PDF прошлой попытки.
2. **Перенесён файл прошлой попытки** из корня `~/vlad/` →
   [prev-attempt_Fender-Redondo-case.pdf](prev-attempt_Fender-Redondo-case.pdf).
   Формы на его картинках кривые, но таблица координат/размеры/раскрой — верные,
   взяты за основу.
3. **Построено лекало** (итог v2):
   [[music/music-vault/systems/guitar-case-blueprint-v2|guitar-case-blueprint-v2.svg]]
   — контур гитары + линия реза кейса (крупнее на ~3 см), вырез справа, голова
   Strat, опоры под гриф/голову, фурнитура (замки ×3–4, петли, ручка), разрез по
   глубине, сетка 10 см, калибровочный квадрат 100×100 мм. Промежуточные v0/v1
   удалены (v0 — неверная форма, v1 — без доработок).
4. **Список материалов (BOM):**
   [[music/music-vault/tasks/guitar-case/materials|materials]].
5. **Исследование практик (2 круга поиска):**

   гибка фанеры (берёзу паром нельзя), фурнитура 3–4 шт, опора под гриф,
   натяг ложемента, климат-контроль 40–55 % (humidipak+гигрометр), альт-материалы
   (коропласт, LiteCase-каркас, стеклопластик), готовые DXF (Electric Herald
   Grellier дредноут, 3axis.co).

## Ключевые решения
- Тип: жёсткий переносной, форма по контуру, кейс > гитары на ~3 см.
- Стенки — гибкая фанера 3–4 мм; дно/крышка — берёза 4–6 мм; углы — бруски.
- Глубина короба 13,5 см (база 8,5 + крышка 5), постоянная; клин деки гасит
  поролон.
