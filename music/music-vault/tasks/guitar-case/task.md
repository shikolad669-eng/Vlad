# Кейс для гитары — жёсткий переносной (берёзовая фанера)

Гитара: **Fender California Debut Redondo CE (Sunburst)** — дредноут **с вырезом
(cutaway)**, голова как у **Fender Stratocaster** (6 колков в линию), мензура 25,5".

## Решение (2026-07-10)
- Тип: **жёсткий переносной кейс**, форма **по контуру** гитары, кейс **крупнее**
  гитары (запас ~3 см на поролон/стенку с каждой стороны).
- Материал: **берёзовая фанера** 5–7 мм (дно/крышка) + гибкая фанера 3–4 мм
  (боковины). Поролон, обивка дерматин/велюр.

## Размеры (из PDF прошлой попытки, приближённые по типовым данным модели)
Гитара: верх. обод ≈29, талия ≈27,5, низ. обод ≈40–41, длина корпуса ≈50,
глубина 10 (у грифа) → 12,5 (у низа), общая длина ≈114–115 см.

Кейс (внутр., +3 см на поролон): длина **119**, у головы 11–12, гриф 9–10,
верх. обод 35, талия 33, низ. обод (макс.) **47**, глубина **13,5** (база 8,5 +
крышка 5), периметр контура ≈ **298 см**.

Контур переносится **методом клеток** — таблица координат на стр. 4 PDF
(половины ширины по Y, справа учтён вырез). Лекало v1 построено по этой таблице.

## Раскрой (из PDF)
- Дно базы — 1 шт, заготовка 119×47, по контуру.
- Крышка — 1 шт, 119×47, тот же контур.
- Боковина базы — полоса 298×8,5, гибкая фанера 3–4 мм.
- Боковина крышки — полоса 298×5, гибкая фанера 3–4 мм.
- Поролон плотный (ложе) 119×47, h 5–7; мягкий (верх) 119×47, h 2–3.
- Обивка дерматин/велюр ≈ 2,5–3 м².
- Фурнитура: рояльная петля (или 3–4 петли), 2–3 замка-защёлки, ручка,
  8–10 защитных уголков, 4–6 резиновых ножек.

Совет из PDF: короб **постоянной** глубины 13,5 см, скос деки компенсировать
толщиной поролона (тоньше у грифа, толще у низа) — проще в сборке.
