# Кейс для гитары — список материалов (BOM)

Под Fender California Debut Redondo CE (дредноут+вырез). Чертёж:
[[music/music-vault/systems/guitar-case-blueprint-v2|guitar-case-blueprint-v2.svg]].
Практики: [[music/music-vault/tasks/guitar-case/best-practices|best-practices]].
Размеры внутр.: длина 119, низ. обод 47, глубина 13,5 см; периметр ~298 см.

## Фанера / дерево
| Деталь | Кол-во | Размер | Материал |
|---|---|---|---|
| Дно базы | 1 | ~119×47 см, по контуру | берёз. фанера 4–6 мм |
| Крышка | 1 | ~119×47 см, тот же контур | берёз. фанера 4–6 мм |
| Боковина базы | 1 полоса | 298×8,5 см (+запас 5 см) | гибкая фанера 3–4 мм |
| Боковина крышки | 1 полоса | 298×5 см (+запас 5 см) | гибкая фанера 3–4 мм |
| Бруски углов (жёсткость) | 6–8 | ~8×2×2 см | сосна/берёза |
| Опора под гриф | 1 | ~10×4 см в сечении | сосна/берёза + поролон |
| Опора под голову | 1 | ~12×3 см в сечении | сосна/берёза + поролон |

> Берёзу паром НЕ гнуть (расслоится) — боковины только гибкая фанера.
> Дно/крышку берём тоньше (4–6 мм) для лёгкости, жёсткость — угловыми брусками.

## Поролон / обивка
| Материал | Кол-во | Примечание |
|---|---|---|
| Поролон плотный (ложе) | 119×47 см, h 5–7 см | выемка режется на ~2–3 мм МЕНЬШЕ обводки (натяг) |
| Поролон мягкий (крышка) | 119×47 см, h 2–3 см | прижим гитары сверху |
| Обивка (велюр / искусств. мех) | ~2–2,5 м² | внутрь, неабразивная |
| Обтяжка наружная (кожзам/толекс/ковролин) | ~2,5–3 м² | легче = лучше |

## Фурнитура
| Наименование | Кол-во |
|---|---|
| Замки-защёлки чемоданные | **3–4** (не 2) |
| Петли — рояльная (или отдельные) | 1 рояльная / или **3–4** |
| Ручка для переноски с площадкой | 1 (на уровне талии) |
| Защитные уголки металлические | 8–10 |
| Ножки резиновые на дно | 4–6 |

## Клей / крепёж / расходка
- Клей столярный ПВА (каркас) + контактный аэрозольный (поролон/обивка).
- Саморезы 3×16 мм, мелкие гвоздики/брадскобы, мебельный степлер + скобы.
- Наждачка (обработка торцов), малярный скотч (стяжка при склейке).

## Инструмент
Лобзик (эл./ручной), шуруповёрт, канцелярский/электронож для поролона,
рулетка, карандаш, гибкая рейка (обводка контура), струбцины/груз.

## Порядок сборки (кратко)
1. Распечатать лекало v2 1:1, склеить, **приложить гитару**, поправить контур.
2. Выпилить дно и крышку по контуру.
3. Согнуть боковины по контуру, приклеить + прибить через 8–10 см, просушить.
4. Усилить углы брусками; вклеить опоры под гриф и голову.
5. Вырезать поролоновое ложе (на 2–3 мм уже обводки), обтянуть тканью.
6. Мягкий поролон — в крышку. Петли — задняя грань, замки ×3–4 — передняя,
   ручка — у талии.
7. Обтянуть снаружи, уголки, ножки. Примерка: гитара не болтается, крышка
   закрывается без давления на деку и гриф.
