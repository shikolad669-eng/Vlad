# media/ — файлы музыки

Аудио, видео, проекты DAW. Содержимое **вне git** (корневой `.gitignore`) —
трекается только этот README.

## Правила

- Имя файла/папки — search-hook: `YYYY-MM-DD-<что-это>` (дата = запись/событие).
- Подпапки (demos/, live/, releases/, stems/, daw/) **рождаются от факта** при
  первой инвентаризации, не выдумываются заранее.
- Каждой значимой единице — карточка-указатель в `../music-vault/` (иначе файл
  потерян для агента).
- Бэкап тяжёлых файлов — отдельная забота (git их не хранит).
