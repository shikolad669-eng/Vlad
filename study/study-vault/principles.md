# Principles — study (deltas)

Follows the **vlad base**: [[vlad-vault/principles|vlad-vault/principles]] +
[[vlad-vault/vault-template|vlad-vault/vault-template]]. Only deltas here.

## Deltas

- **No `market/` zone** — учёба не бизнес; template's mandatory `market/` is
  dropped by this delta (the template itself allows deltas via principles).
- **`notes/` zone added** — конспекты: один файл = одна тема, имя = search-hook.
- **Файлы-материалы по указателю.** PDF/учебники → `~/vlad/documents/` (вне
  git); vault держит карточку (что это, где, зачем).
- **Language.** Конспекты — на языке, на котором Влад думает об этом предмете;
  infra — English (base rule).
