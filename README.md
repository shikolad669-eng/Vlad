# vlad — личный неймспейс

Папка-неймспейс Влада: знание (markdown-vault), домены (музыка, учёба, цех
контента), витрина контента и хранилище файлов — всё в одном репозитории.

Как пользоваться:

- **Обсидиан** открывается на этой папке целиком (корень = vault Обсидиана).
- **Агент** (Claude Code и т.п.) запускается из этой папки — дверь `CLAUDE.md`
  подхватывается автоматически и ведёт в `vlad-vault/HOME.md` (карта знания).
- Структура — зеркало неймспейса Скандара (рождена 2026-07-10 по его
  `vault-template`); наполнение — твоё.

Тяжёлые файлы (музыка/видео/документы) и личный дневник в git не попадают —
см. `.gitignore`. Секреты — только в `secrets/` (никогда не коммитится).

Вход: [[CLAUDE|дверь неймспейса]] → [[vlad-vault/HOME|карта знания]].
