# Принципы vlad-life

Правила живого личного vault'а. Следует конвенции базы vlad
(`../vlad-vault/principles.md`) с личными отличиями.

## Что сюда попадает

Только **первоисточник, которому доверяю** (`trust: primary`):

- дневник, который Влад писал сам или хотя бы валидировал;
- его осмысления, тексты, тексты песен.

**НЕ сюда:**

- производное ИИ (синтезы, дистилляты) — им будет своя зона `derived`, когда
  появятся; сюда только своё;
- тяжёлые файлы (музыка/видео) → `../music/media/` и `../documents/`;
- код и рабочие материалы → рабочие домены.

## Граница доверия

`trust` — метаданное первого класса. Папка = физически прошитая граница:
здесь **бедрок**. Если страница выросла из ИИ-анализа и Влад её не проверил —
ей место не здесь.

## Форма

- Один файл = один объект; frontmatter `title / date / type / tags`.
- Дневник: имя файла `ДД.ММ.ГГ.md`, `type: дневник`.
- Личный регистр: естественный язык, структура не навязывается.
- Никаких секретов (паролей, ключей) в файлах.
- Markdown — портативно: данные переживают любой LLM-инструмент.

## Приватность

Содержимое `diary/` и `inbox/` — в `.gitignore` (структура трекается, контент
локальный). `texts/` трекается (материал для витрины danny-content) — что не
должно уходить даже в приватный репо, живёт в diary.
