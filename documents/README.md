# documents/ — приёмник документов

Документы (сканы, справки, договоры, учебные PDF и т.п.), которым не нашлось
домена. Содержимое **вне git** (см. `.gitignore`) — трекается только этот README.

Правила:

- Имя файла — search-hook: `YYYY-MM-DD-<что-это>.pdf` или говорящее имя.
- Документ, принадлежащий домену, живёт в домене (учебные материалы → `study/`),
  здесь — только внедоменное.
- Ничего чувствительного в git не попадает по построению; если документ нужен
  агенту — в vault кладётся карточка-указатель, не сам файл.

(Аналог у Скандара — зарегистрированный архив вне неймспейса; здесь, в
одно-репозиторном неймспейсе, это зарегистрированная папка в корне.)
