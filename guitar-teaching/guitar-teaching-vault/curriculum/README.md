# curriculum/ — программа обучения

Не путать с [[guitar-teaching/guitar-teaching-vault/lessons/README|lessons/]]
(операционные уроки самого домена, «триггер → правило → почему») — здесь про
**уроки гитары**.

- [[guitar-teaching/guitar-teaching-vault/curriculum/framework|framework]] — схема целиком: треки, уровни, как веса треков собираются из профиля ученика.
- [[guitar-teaching/guitar-teaching-vault/curriculum/modules/README|modules/]] — шесть треков навыка (техника, ритм, теория, слух, репертуар, соло) с рубрикой уровней L0–L3.
- [[guitar-teaching/guitar-teaching-vault/curriculum/intake-template|intake-template]] — диагностика нового ученика (что спросить + что проверить практикой).

Индивидуальный план и уровень конкретного ученика живут в его карточке —
[[guitar-teaching/guitar-teaching-vault/clients/README|clients/]] (шаблон:
[[guitar-teaching/guitar-teaching-vault/clients/_template|_template]]), не здесь — здесь
только общая схема, одна на всех учеников.
