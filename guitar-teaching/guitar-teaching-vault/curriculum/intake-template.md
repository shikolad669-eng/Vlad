# Intake — диагностика нового ученика

Назад к [[guitar-teaching/guitar-teaching-vault/curriculum/framework|framework]] · [[guitar-teaching/guitar-teaching-vault/curriculum/README|curriculum/]]

Проводится на первом уроке (или до него, если формат позволяет). Результат —
профиль + стартовый уровень по трекам, заносится в карточку ученика
([[guitar-teaching/guitar-teaching-vault/clients/README|clients/]]).

## Часть 1 — со слов ученика

- **Возраст** (если ребёнок — кто заказчик: родитель/сам ребёнок).
- **Опыт:** играл ли раньше на гитаре или другом инструменте/вокал; сколько,
  когда бросил и почему (если бросал).
- **Инструмент:** есть ли своя гитара, какая (акустика/электро/классика), в
  каком состоянии, строй проверен?
- **Цель:** зачем гитара — своими словами, не выбор из списка. (Типовые
  ориентиры для сверки с таблицей профилей во [[guitar-teaching/guitar-teaching-vault/curriculum/framework|framework]]
  §3, но не подгонять ответ ученика под готовую строчку.)
- **Вкус:** 3–5 любимых песен/исполнителей — материал для
  [[guitar-teaching/guitar-teaching-vault/curriculum/modules/repertoire|repertoire]].
- **Физика:** леворукость, травмы/ограничения кисти, для детей — усидчивость
  (сколько реально высидит один урок).
- **Время на практику:** честная оценка в неделю, не желаемая.
- **Формат:** очно/онлайн, частота и длительность урока.

## Часть 2 — проверяется практикой, не спрашивается

Даётся сразу на уроке, фиксируется факт, не самооценка ученика:

- Взять гитару, зажать один открытый аккорд (например, Am) — держит ли пальцы
  чисто → база для [[guitar-teaching/guitar-teaching-vault/curriculum/modules/technique|technique]].
- Прохлопать/протопать ровный счёт под метроном 4 такта → база для
  [[guitar-teaching/guitar-teaching-vault/curriculum/modules/rhythm|rhythm]].
- Показать любую табулатуру/схему аккорда — понимает ли, что это → база для
  [[guitar-teaching/guitar-teaching-vault/curriculum/modules/theory|theory]].
- Сыграть две ноты, спросить «выше или ниже» / «фальшиво или нет» на
  расстроенной струне → база для
  [[guitar-teaching/guitar-teaching-vault/curriculum/modules/ear-training|ear-training]].

## Что делать с результатом

1. Проставить стартовый уровень (L0–L3) по каждому треку — по факту части 2,
   не по словам ученика из части 1.
2. Выбрать ближайший профиль из таблицы [[guitar-teaching/guitar-teaching-vault/curriculum/framework|framework]]
   §3, скорректировать веса, если факт разошёлся (например, слух явно выше
   таблицы — взрослый пришёл с вокала).
3. Занести всё в карточку ученика (скопировать
   [[guitar-teaching/guitar-teaching-vault/clients/README|шаблон]]).
