# modules/ — треки навыка

Шесть треков схемы (см. [[guitar-teaching/guitar-teaching-vault/curriculum/framework|framework]]
для того, как они складываются в индивидуальный план). Каждый файл — рубрика
уровней L0–L3 + что разбирать + частые затыки.

- [[guitar-teaching/guitar-teaching-vault/curriculum/modules/technique|technique]] — посадка, руки, аппликатура, баррэ.
- [[guitar-teaching/guitar-teaching-vault/curriculum/modules/rhythm|rhythm]] — темп, штрихи, метроном.
- [[guitar-teaching/guitar-teaching-vault/curriculum/modules/theory|theory]] — аккорды, лады, табы, тональности.
- [[guitar-teaching/guitar-teaching-vault/curriculum/modules/ear-training|ear-training]] — интервалы, подбор на слух.
- [[guitar-teaching/guitar-teaching-vault/curriculum/modules/repertoire|repertoire]] — конкретные песни/пьесы (без универсальной рубрики — под вкус ученика).
- [[guitar-teaching/guitar-teaching-vault/curriculum/modules/improvisation|improvisation]] — соло/лид, включается не всем.
